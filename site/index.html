A FEW GOOD QUESTIONS

Before you
press start.

Is this ready to install on my PS5?+

Not as a verified public release yet. A packaged development candidate exists, but installation, launch, microphone routing, and GPU execution still need console tests. The complete firmware-specific payload setup must also be confirmed. Don't update your console to try this project.

How is Hybrid different from Local lab?+

Hybrid uses local voice processing plus Muse development through your own build relay, producing native app packages. Local lab uses a bundled coding model to make restricted Lua apps inside MuseStation, without a cloud connection. Local lab is a smaller, experimental runtime.

Does the console need PSN or Internet access?+

MuseStation's intended Hybrid setup uses a private LAN connection to your relay. The relay talks to Muse; the console can stay blocked from the public Internet. Local lab can run with networking disconnected. Initial jailbreak and payload setup are separate requirements.

Can it keep creating in the background?+

Keep MuseStation open and the console awake. The current implementation does not support generation in rest mode, after the app closes, or while another game runs. Local projects have budgets and checkpoints, with explicit resume.

Can I connect ChatGPT or another provider?+

Muse is the first planned provider. Other provider connectors and QR/device-code account pairing aren't implemented in this candidate. The current relay contract leaves room for future integrations.
